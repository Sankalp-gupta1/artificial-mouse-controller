Webcam cursor control

Move a cursor with your hand.

The desktop Python project moves the real OS pointer. Browser security prevents websites from taking over your system cursor, so this deployment maps your index fingertip to a safe virtual cursor inside the demo surface. Pinch thumb + index to click.

Camera is off. Processing stays in your browser.
